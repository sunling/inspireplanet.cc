# 每期发布信息与邮件预览

每期内容仍从 `sunling/inspire-planet` 读取，网站不维护第二份会议纪要。详情页上的「预览本期邮件」只向已登录的组织者显示；预览处理公开内容，不涉及订阅者名单。预览内可主动发送测试邮件到当前组织者账号已验证的邮箱。

## 配置发布信息

在内容仓库当期目录按需添加 `episode-publication.json`。字段约定见内容仓库 `events/data-contract.md`：

- `podcast`：真实小宇宙单集的 `url`、`title`，可选实际 `durationSeconds`、`publishedAt`。
- `newsletter`：可选 `intro`、从 0 开始的 `featuredQuoteIndices`（最多 3 条）；邮件导语优先读取 `newsletter.intro`：先简短概括本期精华，再带出真实讨论的 1–2 个问题。没有配置时复用纪要导语，若其中尚未含问句，再接上最多两个现有话题问句；不编新问题。金句优先选 3 位不同分享者的原话。兼容旧的单条 `featuredQuoteIndex`，两个字段不能同时配置。
- 不创建假链接或空播客占位对象。未发布时省略 `podcast`，旧期不要求补文件。

网站读取器扫描元数据文件并按文件 SHA 缓存，目录缓存约 5 分钟。年份和期数共同决定内容身份。错误或缺失的可选元数据不会阻止纪要和卡片显示。

## 预览

完整流程先制作、发布小宇宙，回填内容仓库中的真实单集链接，再整理总结、金句和邮件问题导语。详情页与邮件预览读取同一份播客信息，已回填时无需再次输入。

组织者打开 `/episodes/{year}/{episode}`，点击「预览本期邮件」，检查导语、最多 3 条精选原话和播客入口。原话直接来自本期已整理卡片，保留署名，预览不允许改写。EP42 默认孙玲、Nancy、Wendy 的三句已对照该期转写。可切换邮件样式／纯文字，复制纯文字；对话框内编辑只影响本次预览，关闭不保存。需要长期保存的设置在内容仓库调整。

图片被屏蔽时，邮件里的金句仍是可读文字。预览会列出缺少的纪要、金句或播客；已带入的播客链接和标题可以直接修改；即使选择了“不附播客”，输入框也保持可编辑，填写链接会自动恢复附带播客。未填写链接时，测试邮件自动省略播客，不阻止试发；也可以明确选择本期暂不附播客。填写只用于本次预览及测试邮件，不自动回写正式详情页。

本阶段支持预览及给自己发送测试邮件：需已验证邮箱的组织者账号。服务端从访问令牌取得收件邮箱并检查组织者角色，不接受前端提供的收件人、HTML 或主题。服务端重新读取本期卡片并比对原话与署名；内容变化时要求重新预览。相同请求使用稳定的 Resend 幂等键，失败重试不会因为同一次点击重新生成请求 ID。

测试邮件带有 [测试] 标识，不会发送给订阅者。服务商接受请求不代表邮件已到达收件箱。当前环境需要配置现有 RESEND_API_KEY 与已验证发件地址，未配置会明确报错，不会显示发送成功。

订阅确认、退订、面向订阅者的持久化发送记录、失败重试与额度控制由后续 PR 接入。正式发送模板必须替换预览页脚，提供收件人对应的退订链接及标准退订头；不能把当前预览 HTML 直接作为群发模板。

## 验证

```bash
yarn test src/tests/episodeNewsletter.test.ts src/tests/episodePublicationReader.test.ts src/tests/newsletterPreviewSend.test.ts

```

内容仓库运行 `python3 scripts/check-content.py` 和发布元数据校验测试。首期预览可用现有 EP42 总结和金句；只有取得真实单集链接后才添加播客配置。

## 编辑区、试发与配图

所有编辑框在“编辑邮件内容”区域；“邮件效果预览（只读）”只展示邮件结果，不是在邮件里直接编辑。文字和播客输入框不会因跳过播客或正在试发而锁定。发送按钮仅在请求进行中或同一版本已发送时禁用；必要内容不完整时点击后明确说明原因，不以无解释的灰按钮拦截。

可选配图接受公开 GitHub 图库里的 PNG、JPG、GIF、WebP 图片。可以粘贴 GitHub `/blob/` 图片页面链接，系统自动转换为 `raw.githubusercontent.com` 直链；不使用私有仓库访问令牌或需要登录的地址。邮件 HTML 内嵌图片引用，图片显示在导语下方；提供图片说明和纯文字版链接。图片不是附件，收件客户端是否显示取决于其图片设置。此配置只用于当前预览与试发。
