# 每期邮件：整封编辑、预览与试发

内容仍从 `sunling/inspire-planet` 的当期 `summary.json`、`quote-cards.json`、可选 `episode-publication.json` 读取。完整流程先发布并回填小宇宙，再整理总结、金句和邮件导语；导语先概括具体交流的精华，再带出 1–2 个真实问题。

## 编辑整封邮件

组织者在 `/episodes/{year}/{episode}` 点击「预览本期邮件」，默认进入「编辑正文」：

- 邮件主题独立可编辑；正文中的标题、导语、金句、署名、关注公众号文字都可直接修改。
- 默认尽量选三位不同分享者的原话，底部保留原始金句参考供核对；手工编辑不再被强制替换成生成稿。
- 先点击正文中的位置，再点「插入／修改图片」。支持公开 GitHub blob 图片页面和 raw 直链，自动转换；可插入多张图片。
- 点击图片选中后，可拖动，或使用「上移当前段／图片」「下移当前段／图片」调整位置；也可删除选中图片。上移／下移同样可调整段落。
- 点击已有链接，再点「编辑链接／播客」可修改地址与显示文字；也可在光标位置插入播客或其他 HTTP/HTTPS 链接。
- 支持标题、加粗、斜体、列表、引用、撤销与重做。
- 「邮件效果」和「纯文字」展示当前编辑结果，切换不会丢失修改。「恢复自动生成内容」恢复打开本次对话框时的生成稿和邮件主题。

本次编辑只用于预览和试发，不自动回写正式详情页，也不触发群发；关闭对话框不保存草稿。邮件图片是公开远程引用，不是附件，收件客户端屏蔽图片时会显示图片说明。

## 试发

「发送测试邮件给自己」使用当前主题和整份编辑后的正文，而不是重新生成的内容。缺少播客不影响试发；无效链接、图片或正文会明确提示。请求进行中或同一版本已试发时禁用发送按钮，修改后可再次试发。

服务端验证已确认邮箱与组织者角色，收件人只来自当前会话，不接受前端传入的收件地址。新版接收受限的正文 JSON，由前后端共用的渲染器生成邮件 HTML 和纯文字，限制文档大小／深度、支持的格式、链接协议和 GitHub 图片地址，所有文字和属性均转义，不接受任意 HTML。

主题允许手工修改，限制长度并拒绝换行。新编辑稿允许金句与署名调整；原始引用留在编辑器外供对照，不再把用户明确编辑过的正文按源稿比对回滚。测试邮件保留 [测试] 标识和系统说明，Resend 使用稳定幂等键。服务商接受请求不等于邮件已到收件箱。

当前环境需配置已有 `RESEND_API_KEY` 与已验证发件地址；未配置或服务失败会明确报错，不显示成功。兼容旧测试页面的结构化请求，避免部署切换时破坏已有页面。

订阅者名单、订阅确认、退订、持久化群发记录和正式发送尚未接入；当前只面向自己的邮箱试发。

## 配置默认内容

当期 `episode-publication.json` 的 `podcast` 保存真实 URL、标题、可选成品时长和发布日期；`newsletter` 保存完整导语 `intro` 与最多三个精选金句索引 `featuredQuoteIndices`，兼容旧的单条索引。旧期可不补文件；网站和生成稿共用结构化播客链接。

字段约定见内容仓库 `events/data-contract.md`。GitHub 目录缓存约 5 分钟，文件按 SHA 缓存，年份与期数共同定位。初始邮件不修改真实会议事实；后续编辑由组织者核对。
