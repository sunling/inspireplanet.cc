# 问题圆桌：安排、展开与每期回顾

在 `/admin/question-roundtable`（organizer 权限）管理问题：

1. 会前：填写「展开日期（北京时间）」和「关联期数」，选择「已安排」，保存。
2. 会后：确认实际讨论过，再改为「已展开」并保存。日期经过不会自动代表已讨论。
3. 改期：修改日期和期数后保存；取消安排可改回「待展开」并清空日期和期数。

`/questions` 展示状态、日期及本期链接。`/episodes/{year}/{number}#roundtable`
按实际场次年份和期数读取已安排／已展开的问题。隐藏问题不公开。
提交者勾选的「可参加场次」只表示可用时间，不等于实际安排。
日期和期数必须同时填写；已展开不可选未来日期。已落库的期次会校验日期。
部分期次详情页先于 meetup_episodes 记录存在，因此关联采用期数与场次年份，
不要求提前创建活动报名记录。
