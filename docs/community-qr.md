# 社群与分享者群二维码

管理员在 `/admin/community-qr` 的「选择要更新的群」中选择：

- **启发星球社群**：用于现有的社群入群页。
- **分享者群**：用于每周线上分享会（活动 ID 39）分享申请成功后的入群弹窗。

每周检查并上传新的分享者群二维码；页面显示上次更新时间。两类二维码分别保存，更新一个群不会替换另一个群的图片。切换群时会清除待上传的预览，避免传错群。

分享申请保存成功后才展示入群弹窗；弹窗每次打开都会读取最新图片，不在报名记录中保存旧二维码链接。二维码缺失或读取失败不影响已经提交的申请，页面会提示联系组织者。提交申请不代表分享时间已确认。

接口 `communityQr` 的 `current`（GET）和 `update`（POST）支持 `group=community|speakers`，省略时兼容原社群。上传仍要求 organizer 权限，并保留图片格式与 3MB 限制。使用独立 Storage bucket，首次由管理员上传时自动创建，无需数据库结构迁移。
